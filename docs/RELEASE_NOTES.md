# RELEASE NOTES — PROJECT RHYTHM

Project: PROJECT RHYTHM
Version: 0.1.0 (MVP baseline)
Status: Pre-release

## What's included (Wave 3 MVP target)

- Main menu with play, song library, settings, calibration
- Song selection with catalogue and locked/unlocked states
- One playable song (original/licensed audio)
- Four-lane descending tile gameplay
- Music synchronization via authoritative audio clock
- Touch detection and hit registration
- Scoring: PERFECT / GOOD / MISS, combo, accuracy, grade
- Game-over and results screens
- Restart functionality
- Audio latency calibration (persisted user offset)
- Android debug APK

## What's NOT included (post-MVP)

- Multiple songs / difficulty levels (Wave 4)
- Hold notes, simultaneous notes (Wave 4)
- Endless / Rush / Challenge modes (Wave 5)
- Achievements, daily rewards (Wave 5)
- Multiplayer, leaderboards, cloud sync (Wave 7)
- Licensed music catalogue (Wave 7+)
- Ads, in-app purchases (not planned for first wave)

## Copyright notice

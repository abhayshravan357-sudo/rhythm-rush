## Android export preset configuration (desired)

The Godot 4 Android export preset is configured in the Godot Editor (Project → Export → Android). The following values are specified for MVP-01:

| Field | Value | Notes |
|-------|-------|-------|
| Package name | com.projectrhythm.game | Reverse-domain identifier |
| Version code | 1 (initial), bumped per build | Integer, must increase for each release |
| Version name | 0.1.0 | Semantic version, matches project.godot config/version |
| Icon | res://assets/textures/icon.svg | Referenced by project.godot config/icon; asset not yet created |
| Orientation | Handheld / sensor | project.godot window/handheld/orientation=1 |
| Rendering method | Mobile | project.godot renderer/rendering_method=mobile |
| Debug keystore | Godot default debug keystore | Auto-generated by Godot export |
| Release keystore | TBD — user approval required | Not created; signing requires explicit user approval |
| Permissions | Minimal (see below) | No INTERNET (offline-first) |

Minimal permissions:
- No INTERNET (game is offline-first)
- VIBRATE — optional haptic feedback on note hits
- WAKE_LOCK — keep screen on during gameplay

These values must be applied in the Godot Editor Android export preset. project.godot (shared, Agent 00-owned) already sets config/name="HexaRhythm", config/version="0.1.0", config/icon="res://assets/textures/icon.svg", window/handheld/orientation=1, renderer/rendering_method="mobile", config/features includes "Mobile".
